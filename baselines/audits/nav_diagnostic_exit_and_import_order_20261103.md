The former combined validator checked the report classification but failed to reject these actual process exits. Historical reports, logs, frozen code and receipts remain unchanged.

The current runner only accepts normal Nav exit 0 or 1, with zero exits for validators and any Falcon smoke stage. These reports alone are insufficient to claim a cleanly completed Nav diagnostic.

Falcon's smoke explicitly imports Habitat-Sim before Habitat-Lab. Both Nav logs contain duplicate static-plugin registrations; Falcon's successful smoke does not. This supports an import-order hypothesis, not an established crash cause. The [static-plugin linking PR](https://github.com/facebookresearch/habitat-sim/pull/1861) explains relevant loading behavior but also does not prove causation.
