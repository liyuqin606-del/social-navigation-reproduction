# 追赶 SOTA：第一轮可否定实验

2026-11-05。路线：冻结 Falcon → 动作条件事件时间头 → 经验风险门控 → 单步执行。几何区间验证是独立第二阶段。研究对象先锁定 Social-HM3D 的 position-goal 社会导航；不能以此宣称语言指令 VLN 的 SOTA。

## 已开始实现

core.py：竞争风险累积分布、稳定的删失似然、有限候选经验门控、条件区间检查。test_core.py 的 9 项 CPU 检查通过。model.py 为 PyTorch 小头，H=32、宽128，参数量按层算为104352；本机项目环境未安装 torch，目前只通过语法检查，未完成张量前向、梯度或训练验证。所有时间暂用动作步；不凭控制频率注释换成秒。

这不是训练好的导航模型，没有新的导航结果。区间验证器只检查外部提供的间隙/误差/Lipschitz假设，没有实现合法深度观测到有效人体包络的估计器。UNKNOWN 不是碰撞，经验风险不是安全证书。

## 核心假设

在固定特征、候选支持、数据及近似模型预算下，显式危险时间分布比单一时域碰撞概率改善成功—碰撞权衡。先验证这个假设，再考虑更大世界模型。现有设计中的潜状态递推不是本轮必要条件。

当前接口的 first-action + frozen-Falcon continuation 预测，仅对该续行策略定义。第一轮限定每回合最多一次干预，在开发协议预定的步号触发；不能将其离线校准直接当作每步干预闭环策略的保证。后续逐步介入需要重新采样、训练/校准和闭环评估。

## 可比对象及文献边界

2026-11-05 检索并读取的一手来源：

- [Social-WM v2](https://arxiv.org/html/2609.40177v2)：Table I 的 Social-HM3D 最终位置目标结果为 SR63.77 / SPL49.62 / PSC94.37 / H-Coll21.67。Table II 的位置子目标 SR68.65 属于不同引导设置，不混用。论文采用 RGB 预测；输入模态、行人/动作/目标/数据划分必须进一步逐项核对。这里是论文报告值，不是我们复现值，也不是穷尽检索后的唯一 SOTA。
- [NavThinker](https://arxiv.org/abs/2603.15359)：动作条件预测与 DD-PPO 耦合，是重要直接对照。
- [RoboSense Track2 官方仓库](https://github.com/robosense2025/track2)：深度 Falcon 和允许 RGB-D 的挑战赛轨道要分别标注。挑战赛阶段与原论文完整 val 不默认同一评测。

首轮只要求在本地同协议配对实验超过冻结 Falcon 和等预算直接风险头。正式 SOTA 主张还需要逐项可比协议、最新方法矩阵、完整独立评测、跨场景统计和 Social-MP3D 迁移；超出某一个论文数值不足以成立。

## 三个实验臂

A0：冻结 Falcon 原策略。
A1：直接预测 H 内碰撞/成功等结果的动作评分头；与 A2 相同数据、输入和候选，参数量控制在±5%，另报告实际FLOPs与延迟。
A2：H=32 的事件时间头，短期碰撞风险门控＋成功效用；与 A1 相同候选数及调参次数。H、阈值、干预步号仅在开发集选择一次后冻结。

H8只用作接口诊断；H32仍可能太短，首次必须报告各事件的发生时间分布与右删失比例，不通过增加搜索次数掩盖不可观测性。STOP是终止，不能当等待；失败STOP/超时单独报告。

## 数据与执行顺序

1. 盘点官方 train 场景与许可，按场景身份（包含别名）划分 fit / tune / calibration / confirmation，写出哈希清单。当前本机 baselines/assets 下未找到 train 目录；远端训练资产尚未在本轮核对。正式 val1087、174先导子集、Demo、取消记录不得用于拟合和选参。
2. 在独立运行目录接入采集器：h512、合法目标、剩余时限、真实previous_action、行为概率、逐步碰撞/成功/STOP/超时事件；核对仿真时钟、同时事件优先级、自动reset边界。不能把下一episode观测拼入终止转移。
3. 收集上限100000环境步的开发数据（建议规模，尚未授权提交），保证行为动作支持；没有数据支持的候选拒绝干预。分支排序真值只在完整状态重放验收后使用；否则用随机分配的单次干预试验。
4. 同数据拟合A1/A2，3个初始化种子，开发集选择一次，校准后冻结。对删失、时域Brier评分、早期碰撞漏报和被选动作结果做审查。行政删失不能自动当无碰撞负样本。
5. 建议确认规模：8个独立开发确认场景，每场景10条episode、2个环境种子，160条/臂，共480条；配对相同episode/seed但动作导致的人体轨迹差异属于真实策略效应。全部环境前缀/重放步计入预算。该规模仅筛选，不能证明SOTA。

## Go / No-go（建议预注册，尚无数据）

相对A0并且相对A1：碰撞率至少相对下降20%，同时 SR 和 SPL 点估计退化不超过2个百分点；或者 SR 至少提高3个百分点且碰撞率不升。两个判据不得看到结果后更换主判据，首选前者。PSC、失败STOP、超时必须并列报告，防止靠提前失败降低碰撞。

以场景为重采样单元，保留配对关系，报告95%区间和逐场景差异。小样本区间无法支持改进时判为 INCONCLUSIVE，不能把点估计达标升级成成功。数据泄露、reset错误、非法部署输入、明显失败STOP膨胀则 NO-GO，先修实现。8场景不足以稳定估计宽泛泛化效应，正式阶段必须扩大。
