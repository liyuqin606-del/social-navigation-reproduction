# SCET v0.1：从理论到可训练实验

日期：2026-11-08。当前结论：**首轮学习试验完整结束并通过重放核验；一致性机制未通过收益门槛。**

## 已完成

- 四组模型：带年龄记忆的逐步模型、事件模型、事件模型加停时一致性、三倍训练步数的事件模型。每组恰好 1,313 个参数。
- 128/512 个训练上下文，每个上下文三个固定控制器；三个训练种子，共 24 次拟合。两档数据嵌套，所有模型使用相同可见信息。
- 1,024 个独立留出上下文，精确计算闭环策略的期望成本与碰撞概率。24,576 是模型—上下文评估数，不是独立场景数或真实机器人回合数。
- 原始训练观测、权重、逐上下文结果、训练日志、输入和输出哈希全部保留。
- 六项学习核心检查与六项事件算子检查通过，包含双路径数值梯度、独立逐步 Bellman oracle、期限恢复、零概率条件化与未来信息分支。
- 全部 24 组权重重放通过；独立按原始事件逐项求和复核成本和碰撞概率，通过 81 项输出哈希验证。

## 关键结果

512 个训练上下文下，成本越低越好：

| 模型 | 平均期望成本 | 碰撞概率 |
|---|---:|---:|
| 有记忆的逐步模型 | 11.94772 | 0.02133 |
| 普通事件模型 | 11.65068 | 0.01520 |
| SCET 一致性模型 | 11.65062 | 0.01520 |
| 三倍训练的事件模型 | 11.82026 | 0.02003 |
| 精确模型最优策略 | 11.55065 | 0.01631 |

SCET 相对逐步模型的成本降低约 2.49%，但普通事件模型也取得几乎相同的结果，因此不能归因为新的一致性机制。SCET 与普通事件模型之差的 99% 配对上下文区间跨零。精确最优策略只优化预设成本，所以其碰撞概率不必最小。

门槛预先规定为 SCET 相对三种对照均降低至少 5% 成本并满足碰撞条件；本轮为 NO_GO。原有门槛、模型和留出集没有因结果而改写。

## 失败诊断与路线调整

1. **该环境没有足够的额外改善空间。** 普通事件模型距离精确最优的成本空间仅 0.86%；128 样本档也只有 3.83%。不能指望在同一问题上实现 5% 改善。
2. **相邻前缀约束过于轻微。** 在训练数据上的检查中，乘权重后的一致性梯度范数约为监督梯度的 0.18%–0.25%。当前绝对事件时间输出加生存掩码已实现了大部分年龄条件化。
3. **当前环境只提供“尚未发生”这一新证据。** 还没有执行中获得新的视觉观测，也没有动作改变行人策略。因此这轮不足以检验提案中的完整未来信息模型。

下一轮研究对象应包含可到达的信息边界：执行一个控制器后看到什么、如何据此更新信念并选择另一个控制器。先检查强基线到 oracle 的空间，再锁定实验。保留同信息的逐步信念规划器，避免以缺少记忆或缺少分支的弱对照制造收益。

`stopped_operator.py` 已提供下一步的精确参考语义：

- 联合预测事件时间、事件类型、可观测信息分支；
- RESUME 保留原期限并条件化生存；
- 按实际可观测分支组合后续控制器；
- 显式区分“观察后选动作”与“先固定动作”；
- 无法区分的隐藏分量必须共享后续决策。

该模块是参考算子，不是已训练的感知模型或安全证书。完整 SCET 提案中的价值测试损失、主动观测学习、风险校准和 Falcon 导航效果均未在本轮实现或验证。

## 可复用入口

从项目根目录运行，输出目录必须不存在：

```sh
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -B research/scet_pilot_20261108/run.py --output research/scet_pilot_20261108/runs/NEW_RUN
```

复核已有结果，指定新的核验输出文件：

```sh
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 .venv/bin/python -B research/scet_pilot_20261108/validate.py --run research/scet_pilot_20261108/runs/pilot_a --output research/scet_pilot_20261108/runs/NEW_VALIDATION.json
```

检查学习核心与算子：

```sh
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 .venv/bin/python -B -m unittest discover -s research/scet_pilot_20261108 -p 'test_*.py' -v
```

本轮仅使用本地 CPU；没有改变旧冻结输入、重启暂停的 616 条评测，或提交新 GPU 作业。结果属于有限概率模型学习试验，不是 Falcon 或社会导航 SOTA 成绩。
